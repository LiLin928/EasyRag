**.env 中有**:
```bash

```

**后端代码中**:
```python
# redis_url removed - using PostgreSQL queue
```

**问题**: 项目已改用 PostgreSQL 队列，不再使用 Redis 队列，但 .env 中仍保留 `REDIS_URL` 配置。

**建议**: 删除 `REDIS_URL` 配置行，避免混淆。

### ❌ 问题 2: 缺少 Tracing 配置

后端支持可选的 tracing 功能（langsmith/langfuse），但 .env 中未配置相关参数。

**建议**: 如果需要 LLM 调用追踪，添加以下配置：
```bash

# LangSmith（如果使用）
LANGSMITH_API_KEY=your-api-key
LANGSMITH_PROJECT=easyrag
# Langfuse（如果使用）
LANGFUSE_PUBLIC_KEY=your-public-key
LANGFUSE_SECRET_KEY=your-secret-key
LANGFUSE_HOST=http://192.168.137.13:3030
```

### ❌ 问题 3: 缺少模型配置

后端支持配置默认模型，但 .env 中未配置。虽然可以通过数据库配置，但缺少 seed 默认值。

**建议**: 添加以下配置（可选）：

**建议**: 添加以下配置：

#### 问题 1: PostgreSQL 数据库不匹配

**docker-compose 中**:
```yaml
POSTGRES_DB: easyrag
```

**.env 中**:
```bash
DATABASE_URL=postgresql+asyncpg://easyrag:easyrag2026@192.168.137.13:5432/easyrag_v2
```

**问题**: 
- docker-compose 创建的数据库是 `easyrag`
- 后端连接的是 `easyrag_v2`

**建议**: 
- 方案 1: 修改 docker-compose，创建 `easyrag_v2` 数据库
- 方案 2: 修改 .env，连接 `easyrag` 数据库

#### 问题 2: Langfuse 数据库用户不存在

**docker-compose 中**:
```yaml
DATABASE_URL: "postgresql://langfuse:easyrag2026@postgres:5432/langfuse"
```

**问题**: Langfuse 需要 `langfuse` 用户和 `langfuse` 数据库，但 PostgreSQL 初始化脚本中未创建。

**建议**: 在 `init-db.sql` 中添加：
```sql
-- Langfuse 用户和数据库
CREATE USER langfuse WITH PASSWORD 'easyrag2026';
CREATE DATABASE langfuse OWNER langfuse;
GRANT ALL PRIVILEGES ON DATABASE langfuse TO langfuse;
```
