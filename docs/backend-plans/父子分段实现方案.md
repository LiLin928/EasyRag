# EasyRAG 父子分段实现方案

> 基于 Dify 父子分段思想，结合 EasyRAG 现有的树结构，实现自动生成父子分段元数据

---

## 一、设计理念

### 核心思想

**将章节自动作为父分段，章节内容切分为子分段**：

```
文档结构树：
├── 第一章 招标公告 (TreeNode, level=1)
│   ├── 1.1 项目概况 (TreeNode, level=2)
│   └── 1.2 投标要求 (TreeNode, level=2)
└── 第二章 投标人须知 (TreeNode, level=1)

转换关系：
TreeNode → 父分段
    ↓
    切分子分段（如果内容过长）
    ↓
子分段 → 向量化
```

### 与 Dify 的对应关系

| Dify 概念 | EasyRAG 对应 | 说明 |
|-----------|-------------|------|
| 父分段 | TreeNode | 章节作为父分段 |
| 子分段 | 新增 ChildChunk 表 | 章节内容切分后的检索单元 |
| segment_id | tree_node_id | 子分段通过此关联父分段 |
| 向量化 | 只对子分段向量化 | 父分段不入向量库 |
| 检索 | 检索子分段，映射回父分段 | 保持完整上下文 |

```python
# backend/app/models/child_chunk.py

"""子分段表（父子分段模式下的检索单元）。"""
import uuid
from typing import Optional

from sqlalchemy import Boolean, ForeignKey, Integer, String, Text
from sqlalchemy.orm import Mapped, mapped_column
from sqlalchemy.dialects.postgresql import JSONB
from pgvector.sqlalchemy import Vector

from app.models.base import Base, TimestampMixin, UUIDPk

EMBEDDING_DIM = 1024


class ChildChunk(Base, UUIDPk, TimestampMixin):
    """子分段表。

    父子分段模式下的细粒度检索单元。
    通过 tree_node_id 关联到父分段（TreeNode）。

    Attributes:
        document_id: 所属文档。
        tree_node_id: 关联的树节点（父分段）。
        kb_id: 知识库 ID。
        position: 在父分段内的位置（从 1 开始）。
        content: 子分段文本内容。
        content_search: 全文检索用副本。
        char_count: 字符数。
        embedding: 向量（只对子分段建索引）。
        embedding_model: 向量模型名。
        metadata_: 元数据。
        enabled: 是否启用。
    """

    __tablename__ = "child_chunks"
    document_id: Mapped[uuid.UUID] = mapped_column(
        ForeignKey("documents.id", ondelete="CASCADE"), index=True
    )
    tree_node_id: Mapped[uuid.UUID] = mapped_column(
        ForeignKey("doc_tree_nodes.id", ondelete="CASCADE"), index=True
    )
    kb_id: Mapped[str] = mapped_column(String(36), index=True)
    position: Mapped[int] = mapped_column(Integer, default=1)
    content: Mapped[str] = mapped_column(Text)
    content_search: Mapped[str | None] = mapped_column(Text, nullable=True)
    char_count: Mapped[int] = mapped_column(Integer, default=0)
    embedding: Mapped[Optional[list]] = mapped_column(Vector(EMBEDDING_DIM), nullable=True)
    embedding_model: Mapped[str | None] = mapped_column(String(64), nullable=True)
    metadata_: Mapped[dict] = mapped_column("metadata", JSONB, default=dict)
    enabled: Mapped[bool] = mapped_column(Boolean, default=True)
```

## 三、处理流程设计

### 3.1 完整流程图

```
文档上传
    ↓
解析 → 提取元素
    ↓
构建树 → TreeNode（章节）
    ↓
    ├─→ 传统模式：生成 Chunk
    │    └─ 单层检索
    │
    └─→ 父子分段模式：生成 ChildChunk
         ├─ 为每个 TreeNode 生成父分段内容
         ├─ 判断是否需要切分
         │    ├─ 内容 < 512字符：单个子分段
         │    └─ 内容 > 512字符：切分为多个子分段
         ├─ 子分段向量化
         └─ 检索时映射回父分段
```

### 3.2 新增 ParentChildChunker 类

```python
# backend/app/core/parser/parent_child_chunker.py

"""父子分块器"""

import logging
from typing import List
from app.models.tree_node import TreeNode
from app.core.parser.base import DocumentElement

logger = logging.getLogger(__name__)


class ParentChildChunker:
    """父子分块器

    将树节点（章节）作为父分段，章节内容切分为子分段。

    Args:
        child_chunk_size: 子分段目标大小（字符数）
        child_chunk_overlap: 子分段重叠字符数
        min_child_chunk_size: 最小子分段大小
    """

    def __init__(
        self,
        child_chunk_size: int = 200,
        child_chunk_overlap: int = 50,
        min_child_chunk_size: int = 100
    ):
        self.child_chunk_size = child_chunk_size
        self.child_chunk_overlap = child_chunk_overlap
        self.min_child_chunk_size = min_child_chunk_size

    async def chunk(
        self,
        tree_nodes: List[TreeNode],
        elements: List[DocumentElement],
        doc_id: str,
        kb_id: str
    ) -> List[dict]:
        """
        生成父子分段

        Args:
            tree_nodes: 树节点列表（父分段）
            elements: 元素列表
            doc_id: 文档 ID
            kb_id: 知识库 ID

        Returns:
            子分段列表
        """
        logger.info(
            f"Parent-child chunking: doc_id={doc_id}, "
            f"tree_nodes={len(tree_nodes)}, elements={len(elements)}"
        )

        child_chunks = []

        for node in tree_nodes:
            # 1. 获取该节点的所有元素
            node_elements = self._get_elements_by_node(node, elements)

            if not node_elements:
                continue

            # 2. 生成父分段内容（所有元素拼接）
            parent_content = '\n\n'.join(
                elem.content for elem in node_elements
            )

            # 3. 判断是否需要切分
            if len(parent_content) <= self.child_chunk_size:
                # 短章节：单个子分段
                child_chunks.append({
                    'doc_id': doc_id,
                    'kb_id': kb_id,
                    'tree_node_id': str(node.id),
                    'position': 1,
                    'content': parent_content,
                    'metadata': {
                        'parent_title': node.title,
                        'parent_level': node.level,
                    }
                })
            else:
                # 长章节：切分为多个子分段
                sub_chunks = self._split_parent_content(
                    parent_content,
                    node
                )

                for i, sub_content in enumerate(sub_chunks, start=1):
                    child_chunks.append({
                        'doc_id': doc_id,
                        'kb_id': kb_id,
                        'tree_node_id': str(node.id),
                        'position': i,
                        'content': sub_content,
                        'metadata': {
                            'parent_title': node.title,
                            'parent_level': node.level,
                        }
                    })

        logger.info(f"Generated {len(child_chunks)} child chunks")
        return child_chunks

    def _get_elements_by_node(
        self,
        node: TreeNode,
        elements: List[DocumentElement]
    ) -> List[DocumentElement]:
        """获取树节点的所有元素"""
        # 根据 node.element_ids 或 section_path 过滤
        # 这里简化实现，实际需要根据元素 ID 列表
        return [
            elem for elem in elements
            if elem.tree_node_id == str(node.id)
        ]

    def _split_parent_content(
        self,
        content: str,
        node: TreeNode
    ) -> List[str]:
        """
        切分父分段内容

        优先按句子边界切分，保持语义完整性。
        """
        chunks = []
        start = 0
        text_len = len(content)

        while start < text_len:
            # 计算切分点
            end = min(start + self.child_chunk_size, text_len)

            # 寻找句子边界（优先在句号、问号、感叹号处切分）
            if end < text_len:
                # 向后找句子结束符
                for sep in ['。', '！', '？', '；', '\n']:
                    last_sep = content.rfind(sep, start, end + 50)
                    if last_sep > start + self.min_child_chunk_size:
                        end = last_sep + 1
                        break

            chunk = content[start:end].strip()
            if len(chunk) >= self.min_child_chunk_size:
                chunks.append(chunk)

            # 移动到下一个位置（考虑重叠）
            start = end - self.child_chunk_overlap
            if start < end:
                start = end  # 避免死循环

        return chunks
```

### 5.2 新增保存子分段的函数

```python
async def _save_child_chunks_to_db(
    child_chunks: list[dict],
    doc_id: str,
    kb_id: str
) -> int:
    """保存子分段到数据库

    Args:
        child_chunks: 子分段列表
        doc_id: 文档 ID
        kb_id: 知识库 ID

    Returns:
        保存的子分段数量
    """
    import uuid
    from app.models.child_chunk import ChildChunk

    if not child_chunks:
        return 0

    async with async_session() as session:
        for chunk_dict in child_chunks:
            child_chunk = ChildChunk(
                id=uuid.uuid4(),
                document_id=uuid.UUID(chunk_dict['doc_id']),
                tree_node_id=uuid.UUID(chunk_dict['tree_node_id']),
                kb_id=chunk_dict['kb_id'],
                position=chunk_dict['position'],
                content=chunk_dict['content'],
                content_search=chunk_dict['content'],
                char_count=len(chunk_dict['content']),
                metadata_=chunk_dict.get('metadata', {}),
                enabled=True
            )
            session.add(child_chunk)

        await session.commit()
        logger.info(
            f"Saved {len(child_chunks)} child chunks to database: doc_id={doc_id}"
        )
        return len(child_chunks)
```

## 六、检索流程修改

### 6.1 新增父子分段检索

```python
# backend/app/core/retrieval/parent_child_search.py

"""父子分段检索"""

from typing import List, Dict
from sqlalchemy import select, text
from sqlalchemy.ext.asyncio import AsyncSession

from app.models.child_chunk import ChildChunk
from app.models.tree_node import TreeNode
from app.core.retrieval.vector_search import search as vector_search


async def parent_child_search(
    session: AsyncSession,
    query_embedding: List[float],
    kb_ids: List[str],
    top_k: int = 20
) -> List[Dict]:
    """
    父子分段检索

    检索子分段，映射回父分段返回。

    Args:
        session: 数据库会话
        query_embedding: 查询向量
        kb_ids: 知识库 ID 列表
        top_k: 返回数量

    Returns:
        检索结果列表（父分段）
    """
    # 1. 向量检索子分段
    child_results = await vector_search(
        q_emb=query_embedding,
        kb_ids=kb_ids,
        doc_ids=None,
        scope=None,
        top_k=top_k * 2,  # 检索更多，因为可能多个子分段属于同一个父分段
        metadata_filter=None
    )

    if not child_results:
        return []

    # 2. 提取子分段 ID 和 tree_node_id
    child_ids = [r['id'] for r in child_results]

    # 3. 查询子分段详情（包含 tree_node_id）
    child_chunks = await session.execute(
        select(ChildChunk).where(ChildChunk.id.in_(child_ids))
    )
    child_chunks = child_chunks.scalars().all()

    # 4. 按 tree_node_id 分组，合并评分
    parent_map = {}
    for child in child_chunks:
        node_id = str(child.tree_node_id)

        if node_id not in parent_map:
            # 查询父分段
            tree_node = await session.get(TreeNode, child.tree_node_id)
            parent_map[node_id] = {
                'id': node_id,
                'title': tree_node.title,
                'level': tree_node.level,
                'content': tree_node.parent_content or '',  # 父分段完整内容
                'score': 0.0,
                'children': [],
                'section_path': tree_node.title
            }

        # 更新评分（取最高分）
        child_result = next(
            (r for r in child_results if r['id'] == str(child.id)),
            None
        )
        if child_result:
            parent_map[node_id]['score'] = max(
                parent_map[node_id]['score'],
                child_result['vector_score']
            )
            parent_map[node_id]['children'].append({
                'id': str(child.id),
                'position': child.position,
                'content': child.content,
                'score': child_result['vector_score']
            })

    # 5. 按评分排序，返回 top_k 个父分段
    results = sorted(
        parent_map.values(),
        key=lambda x: x['score'],
        reverse=True
    )[:top_k]

    return results
```

### 7.1 新增检索模式参数

```python
# backend/app/api/v2/retrieval.py

@router.post("/knowledge/{kb_id}/search")
async def search(
    kb_id: str,
    query: str,
    top_k: int = Query(20, ge=1, le=100),
    mode: str = Query("traditional", description="检索模式：traditional(传统) / parent_child(父子分段)"),
    me=Depends(get_current_user)
):
    """
    知识库检索

    Args:
        kb_id: 知识库 ID
        query: 查询文本
        top_k: 返回数量
        mode: 检索模式
    """
    # 生成查询向量
    embedder = Embedder()
    query_embedding = await embedder.embed_query(query)

    if mode == "parent_child":
        # 父子分段检索
        from app.core.retrieval.parent_child_search import parent_child_search

        async with async_session() as session:
            results = await parent_child_search(
                session=session,
                query_embedding=query_embedding,
                kb_ids=[kb_id],
                top_k=top_k
            )
    else:
        # 传统检索
        results = await vector_search(
            q_emb=query_embedding,
            kb_ids=[kb_id],
            doc_ids=None,
            scope=None,
            top_k=top_k
        )

    return ok(results)
```

## 十二、优势总结

### 相比当前方案

| 维度 | 当前方案 | 父子分段 |
|------|---------|----------|
| **检索精度** | 粗粒度（512字符） | 细粒度（200字符） |
| **上下文完整性** | ❌ 可能被截断 | ✅ 完整章节 |
| **语义完整性** | ❌ 可能跨章节 | ✅ 按章节组织 |
| **存储效率** | 每个 Chunk 都有向量 | 只存子分段向量 |
| **可追溯性** | 元素 ID 列表 | 清晰的父子关系 |

### 相比 Dify 实现

| 维度 | Dify | EasyRAG | 说明 |
|------|------|---------|------|
| **父分段定义** | 段落/整篇 | 章节 | 章节更符合文档结构 |
| **数据结构** | 新建表 | 复用 TreeNode | 减少冗余 |
| **检索映射** | segment_id | tree_node_id | 逻辑相同 |
| **实现复杂度** | 高 | 中等 | 复用现有结构 |
